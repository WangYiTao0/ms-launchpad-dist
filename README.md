# MS Launchpad 软件介绍

**一句话：这是公司内部小工具的「应用商店 + 启动器」。** 装好它之后，内部的各个小工具都在同一个窗口里：点一下下载、点一下运行，以后新版本自动送到你电脑上，你不用再管「我手上这个是不是最新版」。

**下载地址：<https://github.com/WangYiTao0/ms-launchpad-app/releases>**（安装方法见下文「怎么安装」）

## 它解决什么问题

以前内部工具是「谁要就发个 zip 过去」：

- 同一个工具，五个人电脑上是五个版本，出了问题先花半天对版本；
- 修了 bug 发新包，总有人还在用旧的；
- 想用某个工具，得先想起来找谁要。

装了 MS Launchpad 之后：**工具在列表里自己找、自己下，版本永远自动保持最新**。工具修了 bug、加了功能，你下次打开时就已经是新的了，不需要任何人再给你发文件。

## 基本功能

### 1. 找工具、下工具、开工具

打开主界面就是工具列表，带搜索框。没下载过的工具点「下载」，几秒到几十秒（取决于工具大小）就好；下载过的直接点「启动」。下载下来的东西会自动做完整性校验（确认文件确实来自维护者、传输中没有损坏），坏包、假包起不来。

<!-- 截图02：某个工具卡片的下载进行中状态，能看到进度。 -->
![下载工具（截图待补）](docs/images/intro/02-下载.png)

### 2. 工具自动保持最新

每次打开主界面，它会自动去对一遍版本清单：哪个工具出了新版，界面上会直接提示，更新下来的还是放在原来的位置，你的使用习惯不受影响。**整个过程不需要你判断、不需要你找人要包。**

### 3. 常用的收藏起来，托盘里一步直达

每天都要开的工具，点收藏。之后不用打开主界面——屏幕右下角托盘图标上点右键，收藏的工具就在菜单里，点一下直接启动。

<!-- 截图03：托盘右键菜单，能看到「打开主界面 / 收藏的工具 / 检查更新 / 开机自启 / 退出」。 -->
![托盘菜单（截图待补）](docs/images/intro/03-托盘菜单.png)

### 4. 软件本体也会自动升级

不光工具会更新，MS Launchpad 自己也会：有新版时窗口里出提示，点一下就在原地把自己换成新版，**不用重新下载安装包、不用重装**。你的收藏和已下载的工具都原样保留。

<!-- 截图04：本体更新提示条（有新版时才出现，可等下次发版时补拍）。 -->
![更新提示（截图待补）](docs/images/intro/04-更新提示.png)

### 5. 开机自启（默认关闭）

托盘菜单里可以勾「开机自启」。勾上之后每次开机它会安静地待在托盘里，不弹窗打扰你，要用的时候随时点开。不想要了取消勾选即可，立刻生效。

## 怎么安装

下载页（公开页面，不用登录任何账号）：

**<https://github.com/WangYiTao0/ms-launchpad-app/releases>**

打开最上面那个版本（标着 Latest），下面的文件二选一：

| 文件 | 适合谁 | 怎么用 |
|---|---|---|
| `MSLaunchpad-vX.Y.Z-win-Setup.exe` | **大多数人，推荐** | 双击安装，装完自动打开 |
| `MSLaunchpad-vX.Y.Z-win-Portable.zip` | 不想安装、或公司电脑限制安装软件的 | 解压到自己的文件夹（别放下载文件夹、别放 C:\Program Files），双击里面的 `MS Launchpad.exe` |

两点说明：

- **不需要管理员权限**，也不需要 IT 帮忙——它装在你自己的用户目录里。
- **不需要装 Python 或其他任何东西**，下载下来就能跑。

## 几个「看着像出问题、其实是正常的」

| 你看到的 | 实际是什么 |
|---|---|
| 点了右上角 X，程序好像没退出 | 正常。它收进右下角托盘了，这样才能在后台帮你盯更新。真要退出：托盘图标右键 →「退出」 |
| 双击了两次，没开出第二个窗口 | 正常。它同时只开一个，第二次双击是把已有窗口叫到你面前 |
| 开机后托盘有图标但没有窗口 | 正常。开机自启就是故意不弹窗的，点托盘「打开主界面」即可 |
| 下载或打开时杀毒软件提示风险 | 内部工具没买商业代码签名证书，新程序被系统多问一句是预期的。**别自己点忽略**，联系维护者或 IT 加白名单，加一次就好 |

最后一条提醒：**只从上面那个官方下载页、或维护者直接发你的渠道拿安装包**，别人转发的、网盘来的不要用。

## 本仓库是什么（技术说明）

本仓是 MS Launchpad 的**公开发布仓**：只存各小程序的编译产物（zip）、`catalog.json` 及其签名。

- **不含源码，不含任何个人姓名 / 工号** —— 所有产物经发布 CI 的姓名 / 路径扫描后才进来。
- `catalog.json` —— 小程序目录清单（总程序读它决定下载什么），由 CI 自动生成 + Ed25519 签名（`catalog.json.sig`）。
- 各小程序的 zip 作为本仓 **Release 资产**发布。

由各小程序仓的发布流水线自动维护，一般不手动改。
