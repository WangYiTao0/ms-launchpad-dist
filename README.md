# MS Launchpad 使用说明

公司内部小工具的统一入口：在这里下载、启动各个小工具，版本自动保持最新。

## 第一步：下载

下载页（不用登录）：**<https://github.com/WangYiTao0/ms-launchpad-app/releases>**

打开最上面标着 **Latest** 的版本，下面的文件二选一：

| 文件 | 怎么用 |
|---|---|
| `MSLaunchpad-vX.Y.Z-win-Setup.exe`（推荐） | 双击安装，装完自动打开 |
| `MSLaunchpad-vX.Y.Z-win-Portable.zip`（免安装） | 解压到自己的文件夹（别放下载文件夹、别放 C:\Program Files），双击里面的 `MS Launchpad.exe` |

不需要管理员权限，不需要装任何其他东西。

## 第二步：下载并启动工具

打开主界面就是工具列表：

- **搜索**：顶部搜索框输入名字，快速找到要用的工具。
- **下载**：没用过的工具点「下载」，几秒到几十秒就好。
- **启动**：下载过的工具直接点「启动」。

## 常用工具：收藏

每天都要开的工具，点**收藏**。之后不用打开主界面——屏幕右下角托盘图标上点右键，收藏的工具就在菜单里，点一下直接启动。

<!-- 截图03：托盘右键菜单，能看到「打开主界面 / 收藏的工具 / 检查更新 / 开机自启 / 退出」。 -->
![托盘菜单（截图待补）](docs/images/intro/03-托盘菜单.png)

托盘菜单里还可以勾「**开机自启**」（默认关）：勾上后每次开机它安静待在托盘里，随用随点。

## 更新：不用你管

- **工具**有新版：打开主界面时自动提示、自动换新。
- **软件本身**有新版：窗口里出提示，点一下原地升级，不用重装；收藏和已下载的工具都保留。

## 这些是正常现象，不是故障

| 你看到的 | 实际是什么 |
|---|---|
| 点了右上角 X，程序没退出 | 收进右下角托盘了。真要退出：托盘图标右键 →「退出」 |
| 双击两次，没开出第二个窗口 | 同时只开一个，第二次双击是把已有窗口叫到前面 |
| 开机后托盘有图标但没有窗口 | 开机自启就是不弹窗的，点托盘「打开主界面」即可 |
| 下载或打开时杀毒软件提示风险 | 内部工具没买商业代码签名证书，被系统多问一句是预期的。**别自己点忽略**，联系维护者或 IT 加白名单，加一次就好 |

只从上面的官方下载页、或维护者直接发你的渠道拿安装包，别人转发的、网盘来的不要用。

## 本仓库是什么（技术说明）

本仓是 MS Launchpad 的**公开发布仓**：只存各小程序的编译产物（zip）、`catalog.json` 及其签名。

- **不含源码，不含任何个人姓名 / 工号** —— 所有产物经发布 CI 的姓名 / 路径扫描后才进来。
- `catalog.json` —— 小程序目录清单（总程序读它决定下载什么），由 CI 自动生成 + Ed25519 签名（`catalog.json.sig`）。
- 各小程序的 zip 作为本仓 **Release 资产**发布。

由各小程序仓的发布流水线自动维护，一般不手动改。
